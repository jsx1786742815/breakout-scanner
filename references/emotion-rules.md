# 情绪周期 + 打板/接力战法规则（龙头战法）

> 两个战法共用一个数据源（涨停池/炸板池/连板梯队），情绪周期决定能不能打板，必须一起看。

## 一、题材/情绪周期（龙头战法）

### 情绪周期五阶段
**冰点 → 修复 → 发酵 → 高潮 → 退潮**，周而复始。

| 阶段 | 特征（量化） | 操作 |
|---|---|---|
| 冰点 | 涨停 <30、连板断层（最高≤2板）、炸板率高 | 空仓等待，不抄底 |
| 修复 | 涨停 30-60、首板增多 | 轻仓试错首板/一进二 |
| 发酵 | 涨停 60-100、最高≥4板、题材扩散 | 做主线龙头首板/二板/空间板 |
| 高潮 | 涨停 >100、连板成群、炸板率 <20% | **高潮日不追，只减仓兑现** |
| 退潮 | 高位炸板/天地板、连板高度骤降、昨日涨停今日亏钱 | **空仓！短线生死线** |

### 核心工具（脚本已内置）
涨停家数、连板高度、炸板率、涨停行业分布。

### 铁律
**退潮期空仓**——这是短线选手区分生死的一条，违反一次可能吃掉一个月利润。

## 二、打板/接力（情绪最强，风险最高）

### 选股
- 只做市场**最高标/龙头**，题材有想象空间
- 封单量大（>1亿）、换手健康（3-15%）

### 买点
| 买点 | 特点 |
|---|---|
| 首板 | 确定性低但溢价高 |
| 二板 | 确认题材 |
| 龙头首次分歧转一致 | 最佳买点（换手充分后再度封板） |

### 卖点
- 次日竞价弱转强 → 持有
- 高开不封板 → 走
- 破位/炸板 → 立即止损

### 难点与生态变化
- 需要极强情绪周期判断
- **20cm 创业板/科创板 + ST 新规后，老一套"数板"玩法已衰减**——不能机械数板，要看题材质量 + 资金态度

## 三、纪律（两战法通用）
1. 退潮期空仓
2. 不接力 ≥3 连板高位（除非龙头首次分歧转一致的确定性机会）
3. 高潮日不追高
4. 只做主线龙头，不做杂毛跟风
