# 低吸战法完整规则（缩量回踩）

> 强势股上涨途中回调缩量买，赌再起一波。与「突破战法」互补：突破=趋势追主升，低吸=回踩埋伏。
> 优点：容错高、适合上班族；缺点：可能"低吸到下跌中继接飞刀"，必须靠"不破前低 + 破均线止损"防飞刀。

## 一、核心逻辑
**强势股回调到关键均线 + 缩量不破位 = 洗盘 → 低吸；破位放量 = 下跌中继 → 不接飞刀。**

## 二、选股条件（强势股）
- 近 20 日涨幅 ≥15%（有趋势，不是横盘杂毛票）
- 均线多头（MA5 > MA10 > MA20，允许 1% 误差）
- 最好在主线板块内

## 三、买点（回踩低吸）
| 买点 | 条件 |
|---|---|
| **MA5 附近（激进）** | 回踩乖离 MA5 在 -3% ~ +2% |
| **MA10 附近（稳健）** | 回踩 MA10，缩量企稳 |
| 缩量 | 回调日量比 < 0.7（缩量=洗盘；放量=出货嫌疑） |
| 不破前低 | 回调低点 > 前一波低点（近20日最低） |
| 分时企稳 | 尾盘不再创新低、有承接 |

## 四、止损（防飞刀）
- **破 MA20 无条件止损**（关键均线失守=趋势破位）
- 或跌破前低（回踩失败确认）

## 五、卖点（反弹兑现）
- 反弹到**前高**附近 → 减仓/走
- **放量滞涨**（反弹放巨量但不创新高）→ 走
- 破 5 日线/10 日线 → 走

## 六、风控
- 大盘弱势不做（低吸战法最怕弱势大盘的"阴跌接飞刀"）
- 单票 ≤20%，分 2 批建仓
- 低吸失败（破 MA20）绝不补仓摊薄

## 七、与突破战法的选择
| 场景 | 战法 |
|---|---|
| 股价放量突破平台/前高 | 突破战法（追主升） |
| 强势股缩量回踩均线 | 低吸战法（埋伏） |
| 大盘强 + 主线明确 | 两者都可用 |
| 大盘震荡/转弱 | 只用低吸（且需主线内），突破战法暂停 |
