# 低吸战法完整规则（缩量回踩）

> 强势股上涨途中回调缩量买，赌再起一波。与「突破战法」互补：突破=趋势追主升，低吸=回踩埋伏。
> 优点：容错高、适合上班族；缺点：可能"低吸到下跌中继接飞刀"，必须靠"不破前低 + 破均线止损"防飞刀。

## 一、核心逻辑
**强势股回调到关键均线 + 缩量不破位 = 洗盘 → 低吸；破位放量 = 下跌中继 → 不接飞刀。**

## 二、选股条件（强势股）
- 近 20 日涨幅 ≥15%（有趋势，不是横盘杂毛票）
- 均线多头（MA5 > MA10 > MA20，允许 1% 误差）
- 最好在主线板块内

## 三、买点（回踩低吸）
| 买点 | 条件 |
|---|---|
| **MA5 附近（激进）** | 回踩乖离 MA5 在 -3% ~ +2% |
| **MA10 附近（稳健）** | 回踩 MA10，缩量企稳 |
| 缩量 | 回调日量比 < 0.7（缩量=洗盘；放量=出货嫌疑） |
| 不破前低 | 回调低点 > 前一波低点（近20日最低） |
| 分时企稳 | 尾盘不再创新低、有承接 |

## 四、止损（防飞刀）
- **破 MA20 无条件止损**（关键均线失守=趋势破位）
- 或跌破前低（回踩失败确认）

## 五、卖点（反弹兑现）
- 反弹到**前高**附近 → 减仓/走
- **放量滞涨**（反弹放巨量但不创新高）→ 走
- 破 5 日线/10 日线 → 走

## 六、风控
- **⚠️ 大盘环境过滤（闸门，2026-08-24 4.5年回测落地，v2 升级为双闸）**：
  - **执行前提：上证收盘站上 MA20 且站上 MA60（双闸）** 才允许低吸；任一跌破 = **低吸闸门关闭**，只观察不买。
  - **回测依据**（82只/2196信号，2022-2026 含牛熊）：弱市 2023 年低吸胜率仅 **38.7%**（红盘回踩 34.4%）、平均亏损；牛市 2024-25 年 53-55% 可用。**低吸是"牛市/强势市专用"战法，弱市做低吸=慢性失血**——比突破战法更需要这道闸。
  - 全周期纯形态低吸胜率 **47.7% <50%**（扣手续费负期望），盈亏比 1.28:1 不达标 → 形态信号必须叠加"大盘过闸 + 主力资金 + 主线板块 + 硬止损"四件套才有正期望。
  - **最优组合（v5 回测，3783信号）**：上证>MA20+MA60 + 红盘回踩 + -5%止损 → 胜率 50.7%、平均 +1.16%/5日、盈亏比 1.59:1、最差 -13.5%（vs 无闸门 -33.4%，尾部风险砍 60%）。这是数据支持的正期望结构。
- 单票 ≤20%，分 2 批建仓
- 低吸失败（破 MA20）绝不补仓摊薄

## 六·五、⚠️ 资金判别：洗盘 vs 出货（2026-08-20 中京电子教训修订）
**主力资金短期流出 ≠ 一定是出货**——缩量回踩 + 主力小幅流出，常是**洗盘**（案例：中京电子 8/18 主力 -1314万 被降级，8/20 定增+算力订单落地直接涨停，主力 +1.15亿 回流）。
资金分级规则（扫描结果按此标注，人工点评时不得一票否决）：

| 资金信号 | 判定 | 动作 |
|---|---|---|
| 主力净流入（>0） | ✅ 健康吸筹 | 正常低吸 |
| 主力小幅流出（≤ 当日成交额 2%，且量比 <0.5 缩量） | ⚠️ **洗盘嫌疑** | **保留观察**，不降级；等催化/板块验证 |
| 主力大幅流出（> 成交额 2%）+ 放量（量比 ≥0.7） | 🔴 出货嫌疑 | 降级，剔除 |
| 主力流出 + 高位 + 放量长上影 | 🔴 出货确认 | 剔除，且提醒规避 |

**洗盘 vs 出货三问**（判断时依次问）：
1. **位置**：回踩发生在趋势中段（20日涨幅 15-60%）→ 洗盘概率高；高位（已翻倍/暴涨后）→ 出货概率高；
2. **板块**：是否在当日活跃主线/板块联动内（如算力 PCB、AI 链）→ 板块共振时洗盘概率高；
3. **催化**：个股近期有无真实事件（定增/订单/行业景气）→ 有催化的缩量回踩，洗盘概率显著上升。

**核心修正**：低吸战法把"缩量<0.7"当洗盘信号，本身就隐含"资金离场也可能是洗盘"——所以**主力流出不该直接否掉缩量回踩的强势股**，尤其有板块联动+事件催化时，应保留观察并提示"洗盘观察位"。

## 七、与突破战法的选择
| 场景 | 战法 |
|---|---|
| 股价放量突破平台/前高 | 突破战法（追主升） |
| 强势股缩量回踩均线 | 低吸战法（埋伏） |
| 大盘强 + 主线明确 | 两者都可用 |
| 大盘震荡/转弱 | **低吸闸门关闭**（回测：弱市低吸胜率仅 38.7%，是慢性失血不是埋伏），突破战法同步暂停；等上证重回 MA20 上方再开闸 |
