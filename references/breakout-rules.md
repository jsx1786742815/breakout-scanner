# 突破战法完整规则（量价确认）

> 右侧追涨波段打法，吃"放量突破平台/箱体/前高"后的主升段（3~15 天）。
> 与「尾盘买入法」（隔日博高开，持 1 天）互补，两套系统不混用。

## 一、核心逻辑（一句话）
**放量突破 = 资金真进场 → 追入；无量突破 = 90% 假突破 → 不碰。**

## 二、选股：突破的"地基"

| 条件 | 标准 |
|---|---|
| 平台/箱体 | 横盘 ≥10 个交易日，振幅 ≤15% |
| 前高/颈线 | 近 60 日最高点 或 箱体上沿 |
| 位置 | 低位平台 > 高位平台 |
| 主线 | 突破票最好在主线板块内（板块共振），孤军突破不碰 |
| 连板红线 | 突破时已 ≥3 连板不追 |

## 三、突破确认：量价三要素

| 要素 | 量化标准 |
|---|---|
| ① 放量 | 突破日量比 **≥1.5（最好 ≥2）**；量比 <1.3 的无量突破 90% 假，一律不碰 |
| ② 有效突破幅度 | 收盘价 **> 颈线 2%~3% 以上**（不是盘中瞬间摸一下） |
| ③ K线质量 | 光头大阳/放量中阳 > 长上影（长上影 = 抛压重） |

量比口径：当日量 / 前一日量（前一日地量时改用 5 日均量）。

## 四、买点

| 买点 | 时点 |
|---|---|
| 激进买点 | 突破当日放量站上颈线时追入 |
| **稳健买点（推荐）** | 突破后**回踩颈线不破、缩量企稳**时买入（二次确认，胜率高） |

## 五、止损：假突破判定与离场

| 信号 | 动作 |
|---|---|
| **跌破颈线 3%** | 无条件止损（假突破确认） |
| 放量长上影（突破日冲高回落） | 立刻走，不等颈线 |
| 次日低开 | 立刻走 |
| 突破后 2 日内放量跌回颈线下方 | 立刻走 |
| 时间止损 | 突破后 5 日不创新高 → 减仓/离场 |

## 六、持有与止盈

| 情形 | 动作 |
|---|---|
| 站稳颈线 + 缩量回踩 | 持有 |
| 滞涨信号（任一触发即卖） | ① 放量滞涨 ② 高位长上影/十字星 ③ 连续 2-3 日不创新高 ④ 跌破 5 日/10 日线 |
| 目标位 | 颈线 + 箱体高度（翻箱目标） |
| 移动止盈 | 从持仓最高点回撤 8%~10% 走 |

## 七、风控铁律

1. **大盘过滤**：大盘站上 MA20 且向上才做突破；弱势大盘直接空仓。
2. **仓位**：单票 ≤ 总仓 20%；分 2 批（突破买一半、回踩确认补一半）。
3. **止损必守**：跌破颈线 3% 无条件走，不补仓摊薄。
4. **只分析不自动下单**。

## 八、实战案例（自检基准）

| 案例 | 走势 | 判定 |
|---|---|---|
| 昊华能源 8/5-8/6 | 放量突破后涨停收 12.72 | ✅ 真突破，持有到 8/7 放巨量滞涨卖 |
| 秦川机床 8/10 | 冲 11.06 突破 10.70 前高后回落收 10.48 | ❌ 假突破（放量长上影），次日该走 |
| 北方稀土 8/7 | 量比 0.68 缩量上涨 | ⚠️ 无量上涨非突破，不碰 |
| 新产业 8/14 | 放量 2.2 突破颈线 50.5 | 观察：回踩 50.5 是否守住 |

## 九、与尾盘买入法分工

| | 尾盘买入法 | 突破战法 |
|---|---|---|
| 逻辑 | 博次日高开（情绪） | 吃主升段（趋势资金） |
| 持仓 | 1 天 | 3~15 天 |
| 买点 | 尾盘 14:50 | 突破日追 / 回踩颈线 |
| 止盈 | 高开冲高即抛 | 持有到滞涨 / 移动止盈 8-10% |
| 适用 | 震荡市、情绪市 | 大盘强 + 主线明确 |

**切换信号**：大盘站上 MA20 且主线板块持续 3 天以上 → 切突破战法；大盘震荡/转弱 → 退回尾盘法。
