# 策略总纲：环境闸门低吸波段系统 v1.0

> 制定日期：2026-08-24 ｜ 依据：2022-2026 四年半回测（3783 信号）+ 用户四维画像访谈
> 顾问声明：**本系统是正期望结构，不是稳赚**。胜率 50.7%、单笔平均 +1.16%、盈亏比 1.59:1、最差单笔 -13.5%（止损后）。回测含幸存者偏差，实盘需按"保守口径"打折（单笔 +0.5%）。

---

## 一、目标（明确量化）

| 项目 | 目标 |
|---|---|
| 年化收益 | **20-30%**（保守口径，回测理想 70%，折半后落此区间） |
| 单笔止损 | **-5% 硬线**（破 MA20 或 -5%，先到先执行） |
| 最大回撤控制 | 账户回撤 ≤ **-15%**（触发即降半仓复盘） |
| 执行频率 | 每周 1-2 笔，全年 40-60 笔，**没信号就空仓** |
| 持仓周期 | 3-5 天/笔 |

## 二、策略定义（四层过滤，全部满足才下单）

```
环境闸门 → 形态信号 → 资金/板块 → 仓位风控
```

### 第 1 层：环境闸门（总开关，决定今天做不做）
- **上证收盘 > MA20 且 > MA60** → 开闸，可扫描可下单
- 任一跌破 → **闸门关闭，只观察不买**（回测：弱市低吸胜率仅 38.7%，是慢性失血）
- 检查时点：每日 15:00 收盘后自动执行

### 第 2 层：形态信号（个股入场券）
- 均线多头排列：MA5 > MA10 > MA20 > MA30（容差 0.99）
- 20 日涨幅 10%~60%（趋势中继，非暴涨末端）
- **红盘回踩**：回踩 MA10，乖离 0~3%，当日收涨（资金承接）
- 当日涨幅 ≤5%（不追暴涨）

### 第 3 层：资金与板块（胜率的另一半）
- 主力资金净流入 ≥300 万（东财 f62，资金裁判）
- 优先当日主线板块内的标的（板块共振，容错高）
- 非 ST、非 688/300/301（权限过滤）

### 第 4 层：仓位与风控
- 单票 ≤ **20%** 仓位，同时持仓 ≤ 2 只
- 单日最多开 1 笔新仓
- 止损：**-5% 硬线 或 跌破 MA20**（先到先走，不补仓不摊薄）
- 止盈：+8%~10% 减 1/3，剩余跟随至破 MA10 或持满 5-8 日

## 三、执行流程（适配"时间不固定"）

| 时点 | 动作 | 你需要做的 |
|---|---|---|
| **每日 15:00 收盘后** | 系统自动：①查闸门 ②扫低吸池 ③输出 1-2 只 + 挂单价/止损 | 花 5 分钟看我给的结果 |
| **次日开盘前** | 决定挂单（挂 MA10，不追价） | 挂单后**不需要盯盘** |
| 挂单成交后 | 止损单同步挂好 | 什么都不用做 |
| **每周五收盘后** | 一次复盘（本周信号质量、执行偏差） | 10 分钟 |
| 触发 -5% 止损 | 自动离场 | 不要看、不要改、不要加仓 |

**关键设计**：所有决策前置到收盘后，盘中零操作——完美适配你"不忙才看"的时间结构。

## 四、漂移防火墙（针对你的 B 反应设计，系统成败的 60%）

**你的风险画像：连亏 3 笔会怀疑策略、想改参数——这是散户亏损第一杀手。以下机制强制生效：**

1. **参数冻结期**：G5 参数冻结 **3 个月**（至 2026-11-30），期间任何连亏/不顺**一律不允许改参数、换战法**；
2. **连亏 3 笔协议**：触发时**不是改策略，而是降半仓**（单票 20% → 10%）继续跑满 10 笔样本，用事实验证，不凭情绪裁决；
3. **顾问否决权**：你想改参数/换战法时，我必须先拦下你，要求你拿出"当前策略跑满 10 笔"的证据，否则拒绝配合修改；
4. **月度体检表**：每月统计 笔数/胜率/盈亏比/最大回撤，与回测基准（50.7% / 1.59）对比，**偏差 >20% 才允许讨论调整**。
