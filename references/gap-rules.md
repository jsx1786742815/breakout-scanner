# 断层补涨战法完整规则（资金断层 + 主线内补涨位）

> 2026-08-31 紫光股份 000938 实盘验证（+8.53%/日，37 成本次日浮盈 +5.27% 站上减仓线）。
> 本质：**资金流只指路，不选股**——用"板块级资金断层"找方向（哪里有钱抱团），用"补涨位+价格结构"选票（买谁、何时买）。修正 2026-08-07"资金=次日裁判"的错误认知（单日资金尖峰买在情绪顶：恒瑞 +9.16亿 → -15.2%）。
> 适用：当日板块批量资金抱团日；**非天天有**，无断层就空仓，与尾盘战法一样是机会驱动。

## 一、核心逻辑（四层）
**① 资金断层识别（方向）→ ② 主线内选补涨位（选股）→ ③ 价格结构确认（买点）→ ④ 排雷+环境（风控）。**

| 层 | 问题 | 答案 | 8-31 实证 |
|---|---|---|---|
| ① 断层 | 钱去了哪个板块？ | 主力净流入榜前列**同一板块≥3只抱团** = 主线候选 | 全市场资金前三：浪潮+6.07/紫光+3.23/烽火+2.19 全在 AI 算力 |
| ② 补涨位 | 板块内买谁？ | **买资金第2-3名 + 当日涨幅最小(<5%) + 价格贴MA20**（乖离 -2%~+3%） | 浪潮资金第一但已涨+4.87%追高；紫光第二、+3.15%、贴MA20(36.98 vs 37.01)起步 |
| ③ 结构 | 什么时候确认？ | **一阳穿三线**（实体覆盖MA5/10/20）或 **长阳修复**（昨收<MA20 今收>MA20）+ **量比≥1.5** | 紫光 8-18冲39.25→回调34.49(-12%)→今日长阳从MA20下方拉回+量比2.16 |
| ④ 排雷 | 什么不能买？ | ST/主力流出/价≥80(一手8000)/688,300,301/大盘弱市 | 非ST、资金正、上证收盘>MA20 |

## 二、选股条件（全部满足）
- **主力净流入 > 0**（当日排雷；净流出直接排除）
- **当日涨幅 < 5%**（越小越优先——补涨位，不是追高；板块第一涨幅已大的不买）
- **乖离 MA20 在 -2% ~ +3%**（贴均线起步，半山腰不碰）
- **量比 ≥ 1.5**（放量异动；无量突破 90% 假）
- 股价 < 80（一手 <8000，适配小资金）
- 非 ST/退、非科创板(688)/创业板(300/301)——用户无权限

## 三、买点/止损/目标
| 项目 | 参数 |
|---|---|
| **买点** | 现价（贴MA20时直接上车）；或等回踩 MA5 不破 |
| **止损** | MA10（近）；或跌破 MA20 无条件走（远）——破位=补涨逻辑证伪 |
| **目标** | 60日前高；按 +5% 减 1/3、+10% 再减 1/3，剩余跟随 |
| **仓位** | 单票 ≤1成；同主线合计 ≤2成（大盘回调环境压缩） |
| **离场** | 放量滞涨走；主线断裂（板块资金转净流出）逻辑止损，不等价格 |

## 四、执行流程（脚本 `scripts/gap_scanner.py`）
```bash
# 自动模式：行业断层识别（f100 行业聚类，主力合计≥1.5亿 且 流入≥3只 = 断层）
python gap_scanner.py                 # 最近交易日
python gap_scanner.py 20260831        # 指定日期
# 概念模式：按关键词找东财概念板块（自动分页拉 BK 列表），成分内选补涨
python gap_scanner.py 20260831 算力    # 算力概念 BK1134
python gap_scanner.py 20260831 算力,机器人
```
脚本输出：断层行业 TOP3 + 每行业补涨候选（穿三线/长阳修复标签、买/止损/目标），存 `gap_result_YYYYMMDD.json`。

## 五、⚠️ 复刻注意点（三条铁律）
1. **买第二不买第一**：断层行业的资金第一名往往已涨高（8-31 浪潮 +4.87%→涨停），买它=追高抬轿。**选资金第2-3名 + 涨幅最小**的。脚本自动过滤涨幅≥5%，人工点评时不得推翻该过滤。
2. **资金断层 ≠ 天天有**：它需要板块批量抱团（≥3只进资金前列），今天没断层=空仓等待，硬做破坏体系。弱市（上证<MA20）禁用，与低吸战法同理（回测：弱市胜率 38.7%）。
3. **资金流只指路不选股**：断层解决"哪个方向"，买点永远由价格结构裁决（贴MA20+穿三线/长阳修复+放量）。单日资金尖峰永不作买入依据——8-07 恒瑞 +9.16亿 买在顶部 -15.2% 是反面教材。

## 六、与其它战法分工
| 战法 | 场景 |
|---|---|
| 断层补涨（本） | 板块级资金抱团日，买主线内"没涨的第二名" |
| 突破战法 | 单票放量突破平台/前高（追主升） |
| 低吸战法 | 强势股缩量回踩 MA5/10（埋伏） |
| 尾盘战法 | 尾盘 14:30-14:50 一阳穿三线（隔日超短，次日卖） |
| 打板/接力 | 情绪最强标（需极强情绪周期判断） |

**优先级**：大盘上证<MA20 → 断层补涨/低吸禁用；断层识别优先于单票形态——先问"钱在哪个板块"，再问"板块里买谁"。
