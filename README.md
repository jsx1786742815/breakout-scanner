# 多战法扫描工具箱（A股）

一套**全平台通用**的 A 股短线/波段「多战法扫描」Agent Skill。用户说一句「根据战法扫描」，即自动拉取**最新行情数据**，按战法筛选符合条件的股票，并输出操作注意事项（买点 / 止损 / 目标位 / 离场信号）。

> 四个战法 · 5 数据源容灾 · 实时取数 · 全平台通用 · 插件式可扩展

---

## ✨ 核心特性

| 特性 | 说明 |
|---|---|
| **四战法** | 突破 / 低吸 / 打板接力 / 情绪周期，覆盖右侧追涨、回踩埋伏、情绪博弈 |
| **5 数据源容灾** | 东财→腾讯→新浪→百度→mootdx 自动降级，主源挂了自动切备胎 |
| **实时取数** | 每次调用先拉最新数据（不用缓存），东财/腾讯/新浪三源实测可用 |
| **全平台通用** | WorkBuddy / Claude Code / Codex / Gemini / Cursor / OpenCode + 通用发现总线 |
| **插件式扩展** | 新增战法 = 加规则文件 + 加扫描脚本 + 加触发词，三步完成 |
| **操作注意事项** | 每个标的都带买点/止损/目标位/离场信号，不是只报代码 |

## 🎯 四个战法

### ① 突破战法（量价确认）— 右侧追主升

**打法**：放量突破平台/箱体/前高时追入，吃主升段（3~15 天波段）。

| 要素 | 量化标准 |
|---|---|
| 放量 | 量比 **≥1.5**（<1.3 的无量突破 90% 假，不碰） |
| 有效突破 | 收盘价 **> 颈线 2%~3%** |
| 平台 | 横盘 ≥10 天、振幅 ≤15% |
| 止损 | 跌破颈线 **3%** 无条件走 |
| 目标 | 颈线 + 箱体高度 |
| 假突破信号 | 放量长上影 / 次日低开 / 2 日内跌回颈线 → 立刻走 |

**触发词**：突破战法 / 放量突破 / 扫一下突破的票

**案例**：昊华能源 8/5-8/6 放量涨停突破（真突破，持有到放量滞涨）；秦川机床 8/10 冲 11.06 突破前高后回落收 10.48（假突破，放量长上影，次日该走）。

---

### ② 低吸战法（缩量回踩）— 回踩埋伏

**打法**：强势股上涨途中回调缩量到 5/10 日线，赌再起一波。

| 要素 | 量化标准 |
|---|---|
| 强势股 | 近 20 日涨幅 **≥15%** |
| 回踩位置 | 乖离 MA5 在 **-3% ~ +2%** |
| 缩量 | 量比 **< 0.7**（缩量=洗盘；放量=出货嫌疑） |
| 不破前低 | 回调低点 > 前一波低点 |
| 止损 | 破 **MA20** 无条件走 |
| 目标 | 前高 |

**触发词**：低吸战法 / 缩量回踩 / 回踩低吸 / 强势股回调

**优点**：容错高、适合上班族；**缺点**：可能"低吸到下跌中继接飞刀"，靠"不破前低+破均线止损"防飞刀。

---

### ③ 打板/接力（情绪最强，风险最高）

**打法**：涨停价排队买入，赌次日高开溢价，或打"空间板"（连板高度龙头）。

| 选股 | 只做最高标/龙头，封单 >1 亿、换手健康（3-15%） |
|---|---|
| 买点 | 首板（确定性低溢价高）/ 二板（确认题材）/ 龙头首次分歧转一致 |
| 卖点 | 次日竞价弱转强持有、高开不封板就走、破位/炸板立即止损 |

**触发词**：打板 / 接力 / 空间板 / 龙头首板

**难点**：需要极强情绪周期判断；**20cm 创业板/科创板 + ST 新规后，老一套"数板"玩法已衰减**，不能机械数板。

---

### ④ 题材/情绪周期（龙头战法）

**打法**：判断市场情绪周期，在冰点/修复期埋伏题材龙头。

**情绪五阶段**：`冰点 → 修复 → 发酵 → 高潮 → 退潮`

| 阶段 | 特征 | 操作 |
|---|---|---|
| 冰点 | 涨停 <30、连板断层（≤2 板） | 空仓等待 |
| 修复 | 涨停 30-60、首板增多 | 轻仓试错首板/一进二 |
| 发酵 | 涨停 60-100、最高 ≥4 板 | 做主线龙头 |
| 高潮 | 涨停 >100、连板成群 | **不追，只减仓兑现** |
| 退潮 | 高位炸板、连板骤降 | **空仓（短线生死线）** |

**工具**：涨停家数、连板高度、炸板率、涨停行业分布（脚本内置）。

**触发词**：情绪周期 / 市场情绪 / 冰点修复发酵高潮退潮 / 龙头战法

## 🚀 快速开始

**方式一：对话触发（推荐）**
```
"突破战法扫一下"
"低吸战法扫一下"
"打板扫一下" / "情绪周期看下"
"根据战法扫描"（自动路由）
```

**方式二：直接跑脚本**
```bash
python scripts/breakout_scanner.py           # 突破战法（最近交易日）
python scripts/pullback_scanner.py           # 低吸战法
python scripts/emotion_scanner.py            # 打板/接力 + 情绪周期
python scripts/breakout_scanner.py 20260814  # 指定交易日
```

## 📦 安装（多平台）

```bash
# 方式一：npx 一键（任意装了 skills CLI 的机器）
npx skills add jsx1786742815/breakout-scanner

# 方式二：脚本
scripts/install.sh        # macOS/Linux
scripts/install.ps1       # Windows

# 方式三：手动复制到目标 agent 的 skills 目录
cp -R breakout-scanner ~/.claude/skills/
```

| Agent | 支持方式 |
|---|---|
| WorkBuddy | `~/.workbuddy/skills/` |
| Claude Code | `CLAUDE.md` / `~/.claude/skills/` |
| Codex | `AGENTS.md` / `~/.codex/skills/` |
| Gemini | `GEMINI.md` / `~/.gemini/skills/` |
| Cursor / OpenCode | 规则入口 + 开放标准 SKILL.md |
| 通用发现总线 | `.agents/skills/<name>/SKILL.md` |

```

    ├── breakout_scanner.py       # 战法① 扫描
    ├── pullback_scanner.py       # 战法② 扫描
```

## 🧩 新增战法（三步）

1. `references/` 加一个规则文件
2. `scripts/` 加一个扫描脚本（`import datasource` 自带 5 源容灾）
3. `SKILL.md` 的 description + 战法清单表加一行，跑 `scripts/sync-skills.sh`
